Die App kann nur ausdrücklich freigegebene Adressbücher lesen. Sie braucht zusätzlich deine Zustimmung für Kontaktzugriff. Notizen, Fotos und Kontaktänderungen sind ausgeschlossen.

Deine Freigabe bleibt bei dir.

Prüfe die angezeigten Server vor der Eingabe. Die Server werden ausschließlich vom Betreiber eingerichtet. Verwende ein App-Passwort, wenn dein Anbieter es unterstützt. Anbieter mit verpflichtendem OAuth sind in dieser Version nicht angebunden. „Verbindung prüfen“ prüft Anmeldung und Kalender- oder Adressbuchliste; es wird nichts gesendet oder verändert.

Die Zugangsdaten werden verschlüsselt übertragen und in geschützten, unverschlüsselten Dateien auf deinem Server gespeichert. Dein Server-Benutzer und root können sie lesen. Anbieterpasswörter können mehr Rechte besitzen als diese Bridge.

Mail, Kalender und Kontakte besitzen getrennte Zugangsdaten. Ein Kontowechsel widerruft die zugehörigen Freigaben. Eine Änderung am Serverprofil verlangt eine erneute Eingabe; alte Kennungen und Vorschauen werden ungültig.
