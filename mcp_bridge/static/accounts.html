Eigene Server

Nur öffentlich erreichbare Server mit geprüftem TLS. Die Bridge prüft DNS und Zieladressen; localhost, private Netze und unverschlüsselte Verbindungen sind gesperrt.

Vollständige CalDAV- oder CardDAV-Adresse mit HTTPS, Port 443 oder 8443. Weiterleitungen auf andere Server werden nicht freigegeben.

Lass die Zwei-Faktor-Anmeldung beim Anbieter aktiviert. Die Bridge kann keinen zweiten Faktor interaktiv abfragen. Verwende ein App-Passwort, wenn dein Anbieter es verlangt oder empfiehlt.
